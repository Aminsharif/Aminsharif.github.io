AI E-commerce Support Chatbot

A production-grade AI support chatbot for e-commerce — intent routing, RAG answers from your knowledge base, live order and product data, human escalation, and full observability behind a secure gateway.

  • n8n
  • OpenAI GPT-4o-mini
  • PostgreSQL + pgvector
  • Shopify

Problem & Solution

Problem

  • Repetitive questions — shipping, returns, order status
  • No instant answers outside business hours
  • Agents manually looking up orders and products
  • No safe escalation path; PII and cost risk with naive bots

Solution

  • Intent routing — FAQ, product, order, shipping, returns, escalation
  • RAG answers with hybrid search & reranking
  • Live order & product data via Shopify sync
  • Human escalation — tickets + Slack/Gmail alerts
  • PII masking & guardrailed LLM replies
  • Secure gateway — auth, rate limits, CORS, size limits
  • Analytics, audit logging & error alerting

The n8n Workflows

Six workflows form the stack: the customer support core with intent routing, a multi-format ingestion pipeline, Shopify customer/order sync, error alerting, and scheduled housekeeping — deployed with Docker and Caddy behind a zero-dependency gateway.

Customer Support Core

Webhook /chat
Webhook — Chat Message POST /webhook/chat
Normalize + Session Lookup Code + Postgres
Switch — Intent Router LLM classified
FAQ Agent — Hybrid Search + Rerank RRF Fusion
Product / Order / Recommendation Agents Live data
Shipping / Returns / Escalation Agents Tickets + alerts
OpenAI — Generate Response guardrailed
Evaluate Faithfulness → Mask PII → Reply Postgres + Code

Every message is routed to the right intent, answered with retrieved or live data, checked for faithfulness, stripped of PII, and replied to — with returns and escalations auto-ticketed and announced on Slack/Gmail.

Data Ingestion Pipeline

Webhook + Cron
Document Ingestion Webhook POST /ingest/document
Normalize + Route by Source Type PDF · CSV · TXT · HTML
Clean Text Code
Compute Checksum → Has Changed? idempotent skip
Chunk Text → Batch Code
Generate Embeddings (OpenAI) batched
Upsert Source + Store Chunks pgvector
Shopify Product Sync hourly + webhook

Ingests FAQs, policies, and docs in PDF/CSV/TXT/HTML form, cleans and checksum-marks them to skip unchanged content, then chunks, embeds, and stores them — plus an hourly and webhook-driven Shopify product sync with variant upserts.

Customer Sync

Hourly + Webhook
Cron — Hourly Customer Sync incremental
Webhook — Shopify Customer Update single mode
Merge Trigger Paths Code
Normalize Customers List Code
Postgres — Upsert Customer on conflict

Keeps the customers table in sync with Shopify — hourly incremental pulls plus real-time webhook updates for individual customers.

Order Sync

Hourly + Webhook
Cron — Hourly Order Sync incremental
Webhook — Shopify Order Update single mode
Merge Trigger Paths Code
Normalize Orders List Code
Upsert Order + Items delete stale

Syncs orders and their line items from Shopify, upserting orders and rebuilding order-item rows so the chatbot always answers with current status and tracking.

Support Error Alerts

Error Trigger
Workflow Error Trigger any failure
Format Error Payload Code
Slack — Notify Support Team channel alert

Catches silent workflow failures and posts a formatted alert to Slack, so the team knows about breakage before customers do.

Housekeeping

Scheduled
Cron — Expire Sessions (hourly) Postgres
Cron — Refresh Affinities (daily) recommendations
Cron — Retention Cleanup (daily) purge old analytics

Scheduled jobs keep the system healthy: expiring stale sessions hourly, rebuilding recommendation affinities daily, and purging old analytics within retention policy.

AI / LLM Layer

GPT-4o-mini drives intent classification, response generation, and reranking; text-embedding-3-small powers hybrid search — with query regeneration and faithfulness evaluation guarding every answer.

Results

What This System Automates

  • Routes every customer message to the right intent — FAQ, product, recommendation, order, shipping, returns, or escalation
  • Answers FAQs from your knowledge base with reranked hybrid search (RRF fusion)
  • Pulls live order status, tracking, and product info from synced Shopify data
  • Creates return and escalation tickets and notifies the team via Slack and email
  • Masks PII in responses and evaluates answer faithfulness before replying
  • Re-embeds only changed documents via checksums to control cost
  • Logs every intent and message for analytics and audit

No campaign metrics have been invented here — measurable numbers will be added once live usage produces them.
