AI Customer Support Agent — RAG + Auto-Ticketing

A multi-channel AI support agent that answers customer questions from your own docs, FAQs, and past tickets — and automatically opens a support ticket whenever it can't answer confidently.

  • n8n
  • OpenAI GPT-4o-mini
  • PostgreSQL + pgvector
  • FastAPI
  • Slack + WhatsApp

Problem & Solution

Problem

  • Slow manual support responses
  • Support team re-answering the same questions
  • No searchable access to docs & FAQs for customers
  • No automatic escalation when the bot can't help

Solution

  • RAG answers from company docs & past tickets
  • Multi-channel coverage — widget, Slack, WhatsApp
  • Auto-ticket creation on low confidence
  • Per-session chat memory
  • Ingestion admin console (manual / files / bulk CSV / JSON)
  • Hybrid search (tsvector + pgvector)
  • Full conversation logging & audit

The n8n Workflows

Four production workflows (plus a FastAPI backend and embeddable widget): knowledge base ingestion, a reusable RAG agent core, a hybrid search tool, and per-channel triggers that route widget, Slack, and WhatsApp conversations through one shared agent.

Chunks and embeds docs, FAQs, and resolved tickets into Postgres with pgvector. Validation and DB failures route to a clean error response instead of crashing the execution.

The reusable RAG agent answers only from retrieved context. When it can't answer confidently, it inserts a ticket and returns a "ticket #N created" message instead of guessing. Final output: {answer, ticket_created, ticket_id}.

Hybrid Search Tool

Fuses Postgres full-text ranking with vector similarity using Reciprocal Rank Fusion, so keyword and semantic matches both surface — with a graceful empty-result fallback when the search fails.

Every channel normalizes input into {channel, session_id, user_identifier, question}, runs the shared agent core, then routes the reply back to the right channel — including the WhatsApp verification handshake.

AI / LLM Layer

GPT-4o-mini powers the RAG agent and text-embedding-3-small powers retrieval, orchestrated through n8n LangChain nodes with Postgres-backed memory and hybrid search.

What This System Automates

  • Answers customer questions from your own docs, FAQs, and past tickets — automatically
  • Covers website widget, Slack, and WhatsApp from a single shared agent
  • Opens a support ticket automatically when the agent can't answer confidently — instead of guessing
  • Keeps per-session chat memory so follow-up questions have context
  • Loads the knowledge base through an admin console (manual, files, bulk CSV/JSON) or a REST API
  • Logs every user turn for audit and analytics, with tickets carrying channel, session, and user identifiers for follow-up

No campaign metrics have been invented here — measurable numbers will be added once live usage produces them.
