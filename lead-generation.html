The n8n Workflows

Four production workflows exported from n8n. Together they cover the full pipeline: discovery & ingestion, AI enrichment & scoring, outreach sending, and reply tracking & follow-up.

Lead Discovery & Ingestion

Manual / HTTP
Run Apify Actor HTTP Request
Map Lead Fields Set
IF Already Exists IF
Crypto — MD5 Lead ID Crypto
Append / Update Leads Sheet Google Sheets

Scrapes local business data, normalizes it into a consistent schema, deduplicates by email, and upserts new leads into the Leads tab with unique MD5 IDs and source tracking.

AI Enrichment & Scoring

Manual
Filter status=new Filter
Loop Over Leads Split in Batches
Fetch Website HTTP
Extract Page Text HTML
Merge Lead + Website Text Merge
AI Score & Extract LLM · gpt-4.1-nano
IF Score ≥ 6 IF
Write Personalized Email Chain LLM
Save Enrichment / Mark Discarded Google Sheets

For each new lead: scrape the website, score fit against an Ideal Customer Profile, extract industry and pain points, write a personalized email — and discard low-fit leads automatically.

Outreach Sending

Manual / Schedule
Read Enrichment Sheet Google Sheets
Filter status=ready Filter
Match Enrichment to Lead Info Merge
Loop Over Ready Leads Split in Batches
Send Outreach Email Gmail
Update Status — Sent Google Sheets
Log to Outreach_Log Google Sheets

Sends one personalized email at a time to respect rate limits, updates each lead to “sent”, and logs every send with a lead_id for tracking.

Reply Tracking & Follow-up

Gmail + Schedule
Gmail Trigger — New Reply Trigger
Extract Sender Email Set
AI Classify Reply LLM
Match Sender to Lead Filter
Log Reply & Update Status Google Sheets
Daily Follow-up Check Schedule Trigger
Filter Needs Follow-up Filter
AI Write & Send Follow-up Chain LLM + Gmail

Detects replies in real time and classifies them with AI (interested / not interested / out-of-office / unsubscribe), then runs daily checks to nudge non-responders — max 2 follow-ups, 3-day spacing.

AI / LLM Layer

Powered by OpenAI (gpt-4.1-nano) through n8n LangChain nodes. Every AI step returns structured JSON, so downstream nodes always receive predictable, validated data.

Results

What This System Automates

  • Replaces manual lead research with automated collection from Apify data sources
  • Normalizes raw scraped data into a consistent schema with unique IDs and source tracking
  • Deduplicates leads using MD5 fingerprints and email matching
  • Scores and qualifies every lead against an Ideal Customer Profile with explainable AI reasoning
  • Generates personalized outreach emails referencing each lead's specific context
  • Sends outreach in controlled batches and logs every send with a lead_id
  • Detects and classifies inbox replies automatically (interested / not interested / OOO / unsubscribe)
  • Runs scheduled follow-ups for non-responders (max 2, 3-day spacing)

No campaign metrics have been invented here — measurable numbers will be added once a live campaign produces them.
