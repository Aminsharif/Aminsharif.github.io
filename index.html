Hello! I’m
Amin Sharif

I am a Full-Stack Developer with over five years of professional experience in building robust and scalable applications using .NET and Angular. Alongside my development journey, I have gained hands-on experience with React Native Expo, which allowed me to expand my expertise in mobile application development.

Recently, I have transitioned into the exciting field of Data Science to harness the power of data and machine learning to drive impactful solutions. To solidify this shift, I completed the iNeuron Full Stack Data Science BootCamp 2.0, where I honed my skills in Python, data analysis, machine learning, and deep learning. Additionally, I have delved into Generative AI by completing a comprehensive course on LangChain and Hugging Face via Udemy, enabling me to work with state-of-the-art AI models and build innovative AI-driven applications.

I am particularly passionate about data scraping and web scraping, creating efficient pipelines to gather and analyze data for actionable insights. My diverse background in software development and data science enables me to craft end-to-end solutions, from developing intuitive front-end interfaces to deploying intelligent back-end models.

In my portfolio, you'll find projects showcasing my expertise in:

Data Science: Machine learning models, data visualization, and predictive analytics.
Generative AI: Applications built with LangChain and Hugging Face.
Web/Data Scraping: Automated data collection pipelines using tools like scrapy, Selenium and BeautifulSoup.
Full-Stack Development: Scalable web applications built with .NET, Angular, and React Native Expo.

When I’m not coding, I enjoy exploring the latest advancements in AI and contributing to open-source projects. Feel free to check out my GitHub to explore my work and connect with me!
